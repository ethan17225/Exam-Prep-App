Supported question types:
  • MCQ — single correct answer (answer is a letter, e.g. "C")
  • SATA — select all that apply (answer is an array, e.g. ["A","C"])
  • FIB — fill in the blank (answer is a text or numeric string)
  • MATRIX — grid of rows × columns with checkboxes (answer maps row index to correct column names)
  • CLOZE — statement with dropdown blanks (answer is one choice per blank, in order)
  • BOWTIE — assign choices to categories, e.g. condition / findings / interventions (answer maps category name to correct choices)
  • RANKING — put items in the correct order (options is the display order, answer is the correct order)
  • HIGHLIGHT — click phrases in a passage (answer is the list of correct token indices, 0-based)
  • HOTSPOT — click a region on an image (regions use percent coordinates; upload the image afterwards via Edit Questions)

Any question type can also carry an image (e.g. an ECG strip) — attach it after upload via the exam's Edit Questions menu.

Patient data sections (optional):

Add a sections array to any question to attach supporting case-study data such as nurses' notes, vital signs, labs, orders or medication records. Each section is one tab: two or more sections render as a tabbed chart above the question.

  • title — the tab label, e.g. "Laboratory Results"
  • blocks — the tab content, in order. Each block is one of:
  • {{ '{' }} "type": "text", "text": "..." {{ '}' }} — a paragraph (line breaks are preserved)
  • {{ '{' }} "type": "list", "items": ["...", "..."] {{ '}' }} — a bulleted list
  • {{ '{' }} "type": "table", "caption": "...", "headers": [...], "rows": [[...]] {{ '}' }} — a data table; caption is optional
